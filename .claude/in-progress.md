## 开发重点领域

### Agent 系统
- **Oracle**: 代码预测和建议
- **Librarian**: 文档检索
- **Frontend Engineer**: UI/UX 开发

### LSP/AST 工具
- 使用 `@ast-grep/napi` 进行代码搜索和替换
- LSP 诊断和补全集成
- 重构支持

### MCP 集成
- Model Context Protocol 服务器支持
- 使用 `@modelcontextprotocol/sdk`
- 精选 MCP 服务器列表

### 构建系统
- Bun 作为主要构建工具
- 跨平台二进制文件构建
- TypeScript 声明文件生成
